Program Java sederhana untuk manajemen kendaraan (Mobil & Motor). Bisa nyalain mesin, jalan, berhenti, dan kontrol AC.

## Struktur File
- `Kendaraan.java` : Abstract class (induk)
- `Mobil.java` : Subclass (implements Berkendara, KontrolAC)
- `Motor.java` : Subclass (implements Berkendara)
- `Berkendara.java` : Interface
- `KontrolAC.java` : Interface
- `Main.java` : File buat ngejalanin program
